# Registro de decisiones de arquitectura (ADR)

Cada decisión técnica relevante se documenta en un archivo `NNNN-titulo.md`, numerado en orden. Una ADR aceptada no se edita: si la decisión cambia, se escribe una nueva que la reemplace y se marca la anterior como **Reemplazada por ADR NNNN**.

Las decisiones de producto siguen registrándose en las actas de reunión de Obsidian (ver `CLAUDE.md`).
